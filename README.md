# Minimalist Life Dashboard

A clean, distraction-free productivity dashboard built with HTML5, Tailwind CSS, and Vanilla JavaScript.

## ✨ Features

- **Dynamic Greeting & Clock**: Real-time display with personalized greetings based on time of day
- **Focus Timer (Pomodoro)**: Customizable countdown timer with audio notifications
- **To-Do List**: Full CRUD functionality with completion tracking
- **Quick Links**: Save and organize your favorite websites
- **Dark/Light Mode**: Toggle between themes with preference saving
- **Local Storage**: All data persists locally in your browser

## 🚀 Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Start being productive!

No build process, no dependencies to install. Just open and use.

## 🎨 Customization

- **Timer Duration**: Change the default 25-minute focus session to any duration
- **Theme**: Toggle between light and dark mode using the button in the top-right
- **Personal Name**: Click on "there" in the greeting to set your own name

## 💾 Data Storage

All your data (tasks, links, name, theme preference) is stored locally using the browser's LocalStorage API. Your data never leaves your device.

## 🌐 Browser Compatibility

Works on all modern browsers that support:
- ES6 JavaScript
- LocalStorage API
- Web Audio API (for timer notifications)

## 📱 Responsive Design

Fully responsive layout that works beautifully on:
- Desktop computers
- Tablets
- Mobile phones

## 🔒 Privacy

- No tracking
- No analytics
- No data collection
- Everything runs locally in your browser
